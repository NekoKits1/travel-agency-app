# public/images
Trip photos, used by the `image` field of each trip (e.g. `/images/lisbon.jpg`).
- File names: lowercase, kebab-case, named after the destination: `lisbon.jpg`, `new-york.jpg`
- Keep images light (under ~300 KB, about 1200 px wide)
- Free photos only (e.g. Unsplash), and note the source in `docs/credits.md`
